# משחקי הקלדה בחלל

משחקי הקלדה לנבו ולענב. אותיות, מילים ותרגילים מגיעים מהחלל, וצריך להקליד אותם לפני שהם נעצרים.

- **ענב בחלל** (`enav.html`): אותיות בעברית, מילים ראשונות עם תמונה, ותרגילי חיבור, חיסור, כפל וחילוק.
- **נבו בחלל** (`nevo.html`): אותיות בעברית ובאנגלית, מילים באנגלית, וחשבון וגאומטריה לכיתות ו׳–ח׳ עם רמזים.

המקש הפיזי קובע ולא שפת המקלדת: ללחוץ על א או על T זה אותו דבר. בטלפון ובטאבלט מופיעה מקלדת על המסך.

הכל רץ בדפדפן, בלי שרת. הדף הראשי (`index.html`) מקשר לשתי האפליקציות.
